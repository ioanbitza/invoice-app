# AI-SDLC Engineer: First-Level Requirements

## Application To Build

Build a simple JavaScript application for managing:

- customers;
- orders;
- order lines belonging to each order.

The application should be a local application. Use `localStorage` for persistence.

Keep the scope light. Functionality may include:

- create, edit, view, and delete customers;
- create orders for customers;
- add, edit, and remove order lines;
- calculate order totals;
- search or filter customers and orders;
- basic validation and useful empty or error states.

The candidate should decide the detailed user experience, data model, and implementation approach, and should explain those decisions. 

## Exercise Expectations

The candidate should plan, build, and review the application using AI. The candidate may choose their own process, tools, design, and implementation approach.

The candidate should review the generated output and take responsibility for the quality of the final application.

## Think Aloud And Record

The candidate is expected to record the work and think aloud during the exercise. They should explain their reasoning, assumptions, decisions, use of AI (which LLM), and review of the resulting code.

The purpose is to understand how the candidate works with AI and how they retain engineering ownership of the final application.

## What We Want To Learn

This exercise should help us understand whether the candidate can:

- turn an incomplete idea into a practical implementation plan;
- use AI effectively while retaining engineering ownership;
- recognise when generated code is incorrect or poor quality;
- build, test, and review a coherent application;
- communicate technical reasoning clearly.
